## 🎯 กฎเกณฑ์การจัดเล่มที่ถอดรหัสจากชุดข้อมูล (KMUTNB Formatting Rules Decoded)

เพื่อให้การทำงานร่วมกับ Skill `academic-project-report` มีความแม่นยำสูงสุด ชุดข้อมูลนี้ยืนยันเกณฑ์มาตรฐานดังนี้:

1. **ระยะขอบกระดาษ (Page Margins)**:
   * ด้านบน (Top): **1.5 นิ้ว** (3.81 ซม.)
   * ด้านซ้าย (Left): **1.5 นิ้ว** (3.81 ซม.) สำหรับเข้าเล่ม
   * ด้านขวา (Right): **1.0 นิ้ว** (2.54 ซม.)
   * ด้านล่าง (Bottom): **1.0 นิ้ว** (2.54 ซม.)
2. **การจัดชื่อเรื่องบนหน้าปก (Title Alignment)**:
   * กรณีชื่อเรื่องยาวเกิน 1 บรรทัด ต้องจัดเป็นรูป **"สามเหลี่ยมหัวคว่ำ" (Inverted Pyramid)** คือบรรทัดบนยาวกว่าบรรทัดล่าง
3. **การจัดวรรคตอนและย่อหน้า (Typography & Indentation)**:
   * ย่อหน้าเนื้อหา (First-line Indent) เท่ากับ **0.5 นิ้ว** (720 twips) สม่ำเสมอตลอดเล่ม
   * ฟอนต์มาตรฐาน: `TH Sarabun PSK` ขนาด 16pt สำหรับเนื้อหา, 20pt หนาสำหรับชื่อบท
4. **มาตรฐานตารางวิชาการ (APA Style Tables)**:
   * มีเฉพาะเส้นแนวนอน 3 เส้นหลัก (เส้นบนสุดหนา, ใต้หัวตาราง, เส้นล่างสุดหนา)
   * **ห้ามมีเส้นขอบแนวตั้ง**
   * ชื่อตารางอยู่เหนือตาราง ชิดซ้าย
5. **มาตรฐานภาพประกอบ (Figures)**:
   * ภาพกึ่งกลางหน้ากระดาษ คำบรรยายใต้ภาพกึ่งกลาง (14pt หนา) พร้อมระบุแหล่งที่มา (12pt เอียง)
6. **สารบัญแบบซิงค์พิกัดหน้าจริง (Two-Pass Dynamic TOC)**:
   * เลขหน้าสารบัญใช้ Right Tab Stop ที่ระยะ **5.77 นิ้ว** พร้อมจุดไข่ปลาเชื่อม (Leader Dots)
