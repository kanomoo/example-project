## 🚀 รายละเอียดโครงงานเด่น (Featured Projects)

### 1. Smart Queue Food (ระบบจัดการคิวอาหารอัจฉริยะ)
ระบบบริหารจัดการคิวและสั่งอาหารสำหรับศูนย์อาหารและร้านอาหาร เพื่อลดระยะเวลาการรอคอย เพิ่มความแม่นยำ และยกระดับประสบการณ์ของผู้ใช้บริการ
- **เอกสารและสไลด์**: เล่มรายงานโครงงานฉบับสมบูรณ์และสไลด์ Pitching จัดรูปแบบตามมาตรฐาน มจพ. (KMUTNB)
- **สคริปต์อัตโนมัติ (`scripts/`)**:
  - `build_report.py`: สร้างไฟล์เล่มรายงาน DOCX จัดฟอร์แมตตามเกณฑ์มาตรฐานวิชาการ
  - `build_presentation.py`: สร้างสไลด์ Pitching Deck (PPTX) แบบมืออาชีพ
  - `generate_graphics.py`: ประมวลผลและสร้างแผนผังทางเทคนิค (System Architecture, BMC, Positioning Map, Risk Matrix)

### 2. ระบบเช็คชื่อด้วยการสแกนใบหน้า (Face Recognition Attendance System)
ระบบบันทึกและตรวจสอบเวลาการเข้าชั้นเรียนอัตโนมัติด้วยเทคโนโลยีรู้จำใบหน้า ครอบคลุมเอกสารตั้งแต่ข้อเสนอโครงงาน บทที่ 1 ถึง บทที่ 5 และภาคผนวกครบถ้วน

### 3. Design Thinking: AEROSEED Kinetic Tyre Dust Air Purifier
นวัตกรรมเครื่องดักจับและฟอกฝุ่นละอองจากยางรถยนต์โดยใช้พลังงานจลน์ พัฒนาผ่านกระบวนการ Design Thinking เพื่อแก้ปัญหามลภาวะทางอากาศในเขตเมือง

## 🛠️ เครื่องมือและการตั้งค่าระบบ (Configuration & Environment)

- **Git Settings**:
  - รองรับการแสดงผลภาษาไทยสมบูรณ์ผ่าน `core.quotepath = false`
  - มีไฟล์ `.gitattributes` กำหนดการจัดการไฟล์ประเภทไบนารี (`.pdf`, `.docx`, `.pptx`, รูปภาพ) อย่างถูกต้อง ป้องกันปัญหา diff ขนาดใหญ่
  - มีไฟล์ `.gitignore` ป้องกันการ commit ไฟล์ขยะระบบ (`.DS_Store`, `Thumbs.db`), ไฟล์แคช Python (`__pycache__`), และไฟล์ชั่วคราวของ Microsoft Office (`~$*`)
